# J04 UI04 browser verification

`make verify-j04` loads the literal fixture in `testdata/devloop-fixture/j04-contract.fixture.json` and its separate `j04-records.ndjson.fixture` source. The J04 command uploads that source explicitly as `j04-records.ndjson`, so the extra records do not enter the other verifier projects. It creates a fresh verification project, then uses Builder controls to create an Observation table and add the contract's five base columns. The driver records the saved workspace identities before and after this browser authoring.

The first required UI contract is the rendered selector `[data-testid="ui04-table-shape-editor"]` on the saved-table Builder route. The selector is declared by the standalone `TableShapeEditor` component, but the Explorer Builder route currently has no runtime render path for that component. If the browser reaches this boundary without the selector, the run stops there and marks aggregate, temporal, unit, recoding, pivot, derived-column, proposal, Preview, Viewer, artifact, contributor, exclusion, and information-loss checks as not proven. It does not author any of those changes through the API.

Each run writes `report.json`, before/after workspace snapshots, Builder DOM captures, a failure screenshot when Chrome can capture one, a redacted network summary, and `J04-evidence.md` under `.artifacts/loom-dev/<session>/<run-id>/`. The run-specific evidence note records the first missing action and its directory.
