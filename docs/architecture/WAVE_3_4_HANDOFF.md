**First-commit compatibility matrix.** The existing registry already calls `CanonicalizeLegacy` on reads. It also fills selector and timestamp fields. Preserve those repairs while extracting the state conversion. On storage read, PENDING maps to QUEUED, PREFLIGHT and LOADING map to RUNNING, and READY maps to PUBLISHED. On HTTP presentation, PUBLISHED renders as READY. The handler also has tests that pass a legacy or future value directly and expect its original spelling. Seed legacy fixtures independently of the new writer. Exercise lease-expired and active-lease cases separately because both start with an in-flight execution. [Registry](../../internal/dataframe/publication/arango/registry.go) · [Bundle model](../../internal/dataframe/publication/bundle.go) · [HTTP witnesses](../../internal/api/dataframe/dataframe/openapihandlers_test.go)

**State contracts that constrain the design.** Release verification includes the observed state in failure details and length-prefixes it into release identity. Keep that value and derive a success predicate. A materialization with a zero-valued state is representable, so the readiness check still has a job. `loomapi.DataframeMaterializationState` is generated as an alias back to the API model, and `PublicationOutput.State` is a plain string. Reversing that alias would introduce an import cycle. For row 16, fieldprofile already imports semantic. Moving the reconciler into semantic requires moving its independent input types down first or keeping the coordination where it is. [Release framing](../../internal/dataset/release.go) · [Generated API](../../api/loomapi/api.gen.go)

**Lease boundary.** The source loader renews three kinds of work, but a file claim also checks plan membership, digest and presence of an existing receipt. Bundle lease renewal uses an owner predicate. Read-pin renewal checks expiry and the competing cleanup owner. Explicit groups persist both a writer token and an expiry, and renew during writes. A generic claim followed by a separate domain update would create a race. The deciding experiment is whether shared renewal code eliminates duplication while each of those checks and its write stay atomic. [Source claims](../../internal/ingest/sourceload/leases.go) · [Read pins](../../internal/dataframe/publication/arango/registry.go) · [Group writes](../../internal/explorer/arango/groups.go)

Three findings materially change the amount of work:

- The contribution spill writer targeted by 682 and 708 disappeared in Wave 1. Row 693's second route-proof function is gone. The execution ledger should credit those prior changes after a symbol check.
- Workspace row values and input references have custom unmarshallers. Imported pivot names distinguish an absent override from an explicit string. Stored receipts have lower-camel JSON tags that several compiler structs lack. A proposed alias must pass accepted **and rejected** input cases, including explicit null, unknown fields and trailing data, plus byte comparison on stored fixtures. Keep the boundary type on divergence. [Workspace construction](../../internal/explorer/workspace/construction.go) · [Stored receipt](../../internal/explorer/receiptmodel/receipt.go)
- The project-ID migration is larger than a search by matching lines suggests. Under production Go files in `internal/`, there are 201 textual calls to `projectid.Canonical` and 73 to `projectid.Legacy`. Legacy itself canonicalizes. Pin the decoded slash, uppercase or underscore legacy prefix, plain lowercase dashed ID, whitespace and malformed-escape cases before replacing either call. ## Execution and acceptance

Use one writer per package per worktree. Independent Wave 4 lanes can run together after the Wave 3 gate. Serialize edits to shared packages such as workspace, compiler/ir and the server composition root. Treat each row marked **fold** as part of the named owning unit. For **probe**, **conditional**, **split**, **reconcile** or **defer**, use the listed witness to choose the safe subset. A failed equivalence check keeps the existing behavior and records the reason. Wave 5 owns release activation, the unified publication transaction and the final Explorer package regrouping.

For paths that move database reads, compiler calls or authorization checks, capture the call count on the same workflow before and after. If the count increases or cache ownership changes, measure that path under the same dataset, scope and warm/cold conditions before landing it.

For each unit, record the source SHA or staged tree digest, exact commands, logs, exits and row IDs. Run `go build ./...`, tests for touched packages and direct importers, and `make lint-go-comments`. Compare all 628 HTTP captures for API/Explorer changes and all 19 render records for compiler, recipe, spec or Explorer compilation changes. Use the corrected immutable-request fixture on both sides of the HTTP comparison. Run `make test-integration` on owned disposable services for storage, Arango, ClickHouse, publication and ingest units and at each wave boundary. Apply the repository's adversarial review to production logic and stored-contract decisions. Run package audit before and after package moves, then its full mode and inspect the edge diff. For any proposed public contract change, trace UI hooks and generated clients, update the schema and callers together, and run UI verification. Re-scan and regenerate the audit at each boundary before closing ledger rows.
